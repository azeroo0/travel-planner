용어

QLoRA
원본 모델을 4bit로 압축해 올린 뒤, 옆에 붙인 작은 저랭크 행렬만 학습하는 방식입니다.
Precision / Recall / F1
Precision은 뽑은 것 중 정답 비율, Recall은 정답 중 찾아낸 비율, F1은 둘의 조화평균입니다.
IoU
두 텍스트 구간이 겹치는 부분을 합친 부분으로 나눈 값입니다. 0.5 이상이면 대체로 같은 근거로 봅니다.
LLM Judge
다른 LLM에게 정답과 모델 출력을 함께 주고 기준별로 채점하게 하는 평가 방식입니다.
Gold / Silver
Gold는 사람이 원문과 대조해 승인한 데이터, Silver는 자동 검사만 통과한 Teacher-LLM 출력입니다.
Record Exact Match
리뷰 하나에 대한 출력 전체가 정답과 완전히 같은 비율입니다.
